# ApexPlanet-Data-Analytics-Internship-Task-4-Advanced-Analytics
Task 4 – Advanced Analytics


## ApexPlanet Data Analytics Internship

This project is part of my **ApexPlanet Data Analytics Internship**. In Task 4, I worked on advanced analytics techniques using the Superstore dataset to extract deeper business insights and build predictive models.

## Objective

The objective of this task was to apply statistical analysis, customer segmentation, clustering, and machine learning techniques to understand customer behavior and improve business decision-making.

## Work Completed

### 1. Statistical Analysis

* Descriptive statistical analysis
* Mean, median, standard deviation and distribution analysis
* Skewness and kurtosis
* Correlation analysis
* Hypothesis testing using statistical tests

### 2. Customer Segmentation

Created customer-level features using an **RFM-style approach**:

* Recency
* Frequency
* Monetary Value
* Total Profit
* Average Discount
* Total Quantity

### 3. K-Means Clustering

Applied **K-Means Clustering** to segment customers into meaningful groups.

Techniques used:

* Feature scaling
* Elbow Method
* Silhouette Score
* Cluster profiling
* Customer segment visualization

### 4. Predictive Analytics

Built machine learning models to predict sales:

* Linear Regression
* Random Forest Regressor

### 5. Model Evaluation

The models were evaluated using:

* MAE – Mean Absolute Error
* RMSE – Root Mean Squared Error
* R² Score

Feature importance was also analyzed for the Random Forest model.
